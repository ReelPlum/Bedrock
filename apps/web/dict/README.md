# Spell-check word list

`en.txt.gz`: English words (American and British spellings) from SCOWL
(Spell Checker Oriented Word Lists) sizes 10 to 60, by Kevin Atkinson, taken
from the `wordlist-english` npm package. One word per line, most common
first (by SCOWL level), which the spell checker uses to rank suggestions.
